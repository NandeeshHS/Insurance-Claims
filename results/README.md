# Results Directory

This folder contains model outputs, predictions, and visualizations generated by the project.

## Structure

```
results/
├── README.md                      # This file
├── predictions.csv                 # Final predictions on test data
├── model_artifacts/                # Trained model files (pickled)
├── visualizations/
│   ├── eda/                        # Exploratory data analysis plots
│   ├── feature_importance/         # Feature importance charts
│   ├── model_comparison/           # Model performance comparisons
│   └── final_predictions.png       # Distribution of final predictions
```

## Contents

### Predictions
- **predictions.csv**: Final predictions for CS, LC, and HALC on the test set
  - CS: Claim Status (probability of claim)
  - LC: Loss Cost
  - HALC: Historically Adjusted Loss Cost

### Model Artifacts
- Saved trained models (XGBoost, LightGBM, GLM)
- Can be loaded for future predictions without retraining

### Visualizations

#### EDA Folder
- Target variable distributions
- Feature correlation heatmaps
- Class imbalance visualizations
- Missing values analysis

#### Feature Importance Folder
- Top feature rankings from Random Forest
- Feature importance from XGBoost/LightGBM
- Feature selection results

#### Model Comparison Folder
- ROC curves for classification
- Confusion matrices
- Approach A vs Approach B comparison
- Residual plots for regression
- Actual vs Predicted scatter plots

## Generating Results

Results are automatically generated when running:
1. `python main.py` (requires data files)
2. Jupyter notebooks in `notebooks/` folder
3. Individual model scripts in `src/` folder

## Notes

- All visualizations are saved as high-resolution PNG files (300 DPI)
- Results may vary slightly due to random seed initialization
- For reproducibility, ensure `RANDOM_SEED = 42` in `src/config.py`
